# Coding-A2---Sade-inspired-study-loop--Tahlia-Williams
A music loop for studying and focusing inspired by the background music in Sade's songs. 
# General Information
- Purpose: to make music to study to, as a code prototype for my Creative Coding project.
- Why I made it: I wanted to make a music free study loop, as i have struggled to focus with music with lyrics. 
- Inspiration: Sade's relaxed, jazzy style, without the lyrics to match the aim. 
## Technologies Used
- TunePad (tunepad.com), a browser-based platform for making music with Python
- Settings: 100 bpm, 4/4 time, C major
## Features
- 4 layers: piano, drumkit, electric bass, guitar
- `for` loops repeat each pattern, so the song lasts about 67 seconds (112 beats at 100 bpm)
## Setup
1. Go to tunepad.com and create a free account.
2. Create a new project and set it to 100 bpm, 4/4 time, C major.
3. Add a cell for each code file in this repository and set the instruments.
4. Write each file's code into the matching cell.
## Usage
Press the main play button at the top right of TunePad. Use the Mixer tab to adjust each layer's volume.
## Room for Improvement
- If i had more time i would add more variation so it does not get repetitive.
